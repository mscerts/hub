## Typography

### Headings and inline formatting

Regular text can contain **strong text**, *emphasis*, ~~strikethrough~~, `inline code`, and [a normal link](https://learn.microsoft.com/).

Use <mark>highlighted text</mark>, <kbd>Ctrl</kbd> + <kbd>K</kbd>, and <small>small supporting text</small> when the context calls for it.

#### A fourth-level heading

> Documentation should be clear enough to use and honest enough to trust.
>
> This is a multi-paragraph blockquote with a [quoted link](https://msfthub.com/).

## Lists

Unordered lists support nesting:

- Microsoft Azure
  - Compute
  - Storage
  - Networking
- Microsoft 365
- Security, Compliance, and Identity

Ordered lists support nesting too:

1. Choose a path.
2. Read the study guide.
   1. Review the skills measured.
   2. Identify the gaps.
3. Practice deliberately.

Task lists are useful for editorial checklists:

- [x] Confirm the page title
- [x] Check the mobile layout
- [ ] Review external links before publishing
