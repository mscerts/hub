## Audience profile

As a candidate for this Microsoft Certification, you should have experience using generative AI-powered productivity tools, including Microsoft 365 Copilot, Copilot Cowork, and pre-built agents. You take advantage of AI and Work IQ to improve daily work, drive business outcomes, and make informed decisions in business contexts without building AI apps or writing code.

You should have experience using elements of generative AI, such as prompt engineering, context engineering, and large language models, and using Microsoft 365 Copilot tools such as notebooks and pages. You should understand how these elements are used to drive more efficient business outcomes.

You should be comfortable using Microsoft 365 core apps such as Outlook, Word, Microsoft Teams, PowerPoint, and Excel. You should be familiar with common business processes, including drafting emails, creating presentations, generating images, and managing documents.
