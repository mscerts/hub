## Audience profile

As a candidate for this certification, you are in business professional roles including, but not limited to, product manager, program manager, technical project manager, and business analyst. You use GitHub and GitHub Copilot to improve the quality, speed, and scale of daily work. You accelerate operational efficiency, create workflows for business, collaborate more effectively, and increase productivity by using GitHub and GitHub Copilot-without needing deep software development or coding experience.

While candidates for this exam are not necessarily software developers, solutions architects, or software engineers, they are seeking to improve business processes, increase technical fluency, and optimize outcomes by using Agentic AI.

You may work closely with other business stakeholders, including but not limited to technical professionals across your organization to design, develop, and implement business processes and workflows that effectively and reliably support the needs of your business.

You should have some experience using generative AI and it may be helpful to have some familiarity with GitHub features and capabilities. You should have experience producing business output that meets business requirements. You should also have experience managing projects, products, or processes, in a business context and making or influencing business decisions about quality, speed, risk, and control.

### Your responsibilities for this role include

- Using GitHub productivity platform features
- Enhancing productivity by using GitHub Copilot
- Designing and implementing agentic workflows and automations
- Performing human-in-the-loop tasks for agentic workflows

### You should also have experience with

- Understanding considerations for versioning workflows
- Understanding differences between GitHub Copilot Chat in github.com, GitHub Copilot App, and GitHub Copilot CLI
- Assessing workflow impact and business value
- Differentiating between GitHub Copilot cloud agents and custom agents
- Understanding considerations for GitHub Copilot security
