:::caution
Exam and its certification, Microsoft Certified: DevOps Engineer Expert, are being retired on February 1, 2027.

It will be replaced by [AZ-401: Designing and Implementing Microsoft Agentic DevOps Solutions](/certs/azure/az-401/), which is in beta now and leads to the new Microsoft Certified: Agentic DevOps Engineer Expert certification.

Microsoft announced the retirement together with the new exam: [read the announcement on the Skills Hub blog](https://techcommunity.microsoft.com/blog/skills-hub-blog/new-microsoft-certified-agentic-devops-engineer-expert/4528356?WT.mc_id=studentamb_165290).

Microsoft Learn always takes a while to update with certification retirements so don't panic if you can't see it there yet.
:::
