:::note
Effective October 6, 2026, Microsoft renamed the certification to Microsoft Certified: Azure Cosmos DB AI Developer Associate (previously Azure Cosmos DB Developer Specialty) and updated this exam, now titled Building AI Applications with Azure Cosmos DB. The exam code is still DP-420. See the [study guide](https://learn.microsoft.com/credentials/certifications/resources/study-guides/dp-420?WT.mc_id=studentamb_165290) for the skills measured as of October 6, 2026 and [Microsoft's announcement](https://techcommunity.microsoft.com/blog/skills-hub-blog/updates-to-azure-cosmos-db-and-power-platform-developer-certifications/4528353?WT.mc_id=studentamb_165290). MeasureUp and Pluralsight still list the previous exam name, Designing and Implementing Cloud-Native Applications Using Microsoft Azure Cosmos DB, so their material may not yet cover the October 6, 2026 update.
:::
