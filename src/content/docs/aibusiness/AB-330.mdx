:::note
The beta period began on October 16, 2026. Microsoft usually announces a new beta exam on the [Skills Hub blog](https://techcommunity.microsoft.com/category/skills-hub/blog/skills-hub-blog?WT.mc_id=studentamb_165290) with an 80% discount code for the first 300 candidates. That announcement has not been published for this exam yet and should arrive within a few days, so check back before you pay full price. Microsoft usually releases a beta exam as generally available [10-12 weeks after the beta period begins](https://learn.microsoft.com/credentials/support/about-beta-exams?WT.mc_id=studentamb_165290), so counting from October 16, 2026 this exam is expected to leave beta between December 25, 2026 and January 8, 2027. Beta scores are released about 10 days after that, so expect results between January 4, 2027 and January 18, 2027. These dates are estimates and can shift, and waiting for a score can take up to 14 weeks. See the [Beta Exams](/certs/vouchers/betaexams/) page for more information about the 80% discount and early access to codes.
:::
