GitHub Learn at GitHub Universe 2026 Preview is a free Microsoft Reactor livestream on **October 21, 2026, 6:00-7:00 PM UTC**, hosted by Ari LiVigni (Senior Learning Advocate at GitHub). The session introduces **GH-700 (beta): Enhancing Operational Efficiency with Agentic AI**, a new exam leading to the GitHub Certified: Agentic AI for Business Professionals certification, aimed at product managers, program managers, technical project managers, and business analysts. See the [GH-700 exam page](/certs/github/gh-700/) for what's known about the exam itself.

## How to get the voucher

<Steps>

1. [Register for the event](https://developer.microsoft.com/en-us/reactor/events/27591/) with your email (or sign in with a Microsoft Account).
2. Attend the livestream on October 21, 2026, 6:00-7:00 PM UTC.
3. The exclusive exam voucher code is given out at the end of the broadcast.

</Steps>

:::tip
No registration deadline, discount percentage, country exclusions, or redemption window has been published yet. Check the [Beta Exams](/certs/vouchers/betaexams/) page for how Microsoft's beta exam vouchers generally work in the meantime.
