No new Virtual Training Days events are currently being planned, so there is no way to earn this discount right now. This page is kept as a reference for learners who already attended an event, and it will be updated if Microsoft brings the events back.

:::note
Attendees received a 50% exam voucher for all fundamental exams and SC-200, AI-103, DP-300, SC-401, SC-500.
:::

## How does it work?

<Steps>

1. Register for the event
2. Attend all the sessions
3. 5-10 days after the event finishes, you will receive the voucher (See here how to redeem it [How to schedule an Exam and redeem vouchers](/certs/guide/schedulingexam/#checkout-and-redeeming-voucher-codes). It is voucherless discount so it is important the email address is added to your Microsoft Learn account.)
4. You must schedule and take the exam within 90 days from the event date. Usually you can take the exam later than 90 days but it is at your own risk and support won't help you if something goes wrong, like the exam crashing.
5. For students, with the [student exam discount](https://learn.microsoft.com/credentials/certifications/student-discounts?WT.mc_id=studentamb_165290), this adds up to **65%** discount

</Steps>

:::note
[**Microsoft Virtual Training Days Discounted Certification Exam FAQ**](https://aka.ms/MVTD_FAQ_EN)
:::

:::caution
The discount is voucherless and, according to the FAQ, cannot be redeemed in restricted countries and regions: Afghanistan, Bangladesh, Benin, Cameroon, Gambia, Ghana, Nigeria, Pakistan, Senegal, Tanzania, Togo, and Uganda. Learners in these regions must purchase a 100% voucher to complete their exam registration via Mind hub. See the [FAQ](https://aka.ms/MVTD_FAQ_EN) for details.
:::
