:::note
SC-100 is an architect-level exam. It is about designing security solutions and understanding the architecture behind them, so knowing architecture is what matters most. Hands-on technical experience helps, but the exam does not primarily test it and doing labs is not required. Labs can still support your preparation by making the services you design with more concrete, so use the case studies first to practise design decisions and treat the Applied Skills and labs as optional extras.
:::
