:::caution
As per [GitHub's certification renewal](https://learn.github.com/credentials), the GH-900 GitHub Foundations certification is a fundamentals certification and does not expire or require renewal.

Despite that, your certification dashboard is going to say that your certification is expiring in 2 years. This is a bug in the system. 

If you are nearing the certification expiry date, contact the [GitHub Certification team](mailto:gh-certification@service.microsoft.com) to escalate this issue if it is not fixed by then ([they might say they are not responsible and instead you need to contact the general certification support](https://engagehub.microsoft.com/#view/Microsoft_AzureCXP_EngageHub/MsaLanding.ReactView/targetExperience/sfb/sapId/de16815f-2fa5-576e-4946-70cae21a4eeb)).
:::
