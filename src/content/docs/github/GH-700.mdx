:::tip
This exam has been announced but is not yet available on Microsoft Learn - there is no exam page, study guide, or certification page to link to yet, so this page is intentionally sparse.

What's known so far comes from a GitHub Learn session at the GitHub Universe 2026 Preview (a Microsoft Reactor livestream, October 21, 2026): GH-700 leads to the **GitHub Certified: Agentic AI for Business Professionals** certification, targets product managers, program managers, technical project managers, and business analysts, and covers using GitHub Copilot, custom agents, Model Context Protocol integrations, and workflow automation. GitHub's own announcement refers to it as a beta exam, though it doesn't have a Microsoft Learn presence yet to confirm that against.

We'll fill this page in with verified official resources once the exam is actually published.
:::
